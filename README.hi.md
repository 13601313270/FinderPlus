# Finder+

macOS के लिए नोड-आधारित विज़ुअल ऑटोमेशन कैनवास। नोड्स को एक अनंत कैनवास पर खींचें, उनके पोर्ट्स को आपस में जोड़ें, और डेटा ग्राफ़ से होकर बहता है — टेक्स्ट, इमेज, LLM कॉल, HTTP रिक्वेस्ट और शेल कमांड को एक ऐसी पाइपलाइन में बदल दें जिसे आप देख सकते हैं और दोबारा इस्तेमाल कर सकते हैं।

## यह क्या है

Finder+ **विज़ुअल वर्कफ़्लो** बनाने के लिए एक डेस्कटॉप ऐप है। स्क्रिप्ट लिखने के बजाय, आप नोड्स को कैनवास पर रखते हैं और एक आउटपुट पोर्ट को एक इनपुट पोर्ट से जोड़ते हैं। मान तारों के साथ आगे बढ़ते हैं, और जैसे ही किसी नोड के इनपुट पहुँचते हैं, वह अपने परिणाम के साथ जगमगा उठता है।

आम उपयोग:

- इमेज का बैच प्रोसेसिंग: क्रॉप → कंप्रेस → क्वालिटी समायोजित करें → बैकग्राउंड हटाएँ
- प्रॉम्प्ट पाइपलाइन बनाएँ: टेक्स्ट टेम्पलेट → LLM → JSON डिस्प्ले
- टेक्स्ट प्रॉम्प्ट से इमेज बनाएँ और परिणाम को एक फ़ोल्डर में डालें
- प्रोग्राम लिखे बिना HTTP API और लोकल शेल कमांड को आपस में जोड़ें

## डाउनलोड

नवीनतम रिलीज़: **<https://github.com/13601313270/FinderPlus/releases>**

`.dmg` खोलें, **Finder+** को **Applications** फ़ोल्डर में खींचें, फिर डिस्क इमेज को इजेक्ट करें।

### macOS पर पहली बार लॉन्च

> **यह बिल्ड अभी साइन या नोटराइज़ नहीं किया गया है।** पहली बार macOS इसे रोक देगा, संदेश कुछ इस तरह होगा *"डेवलपर सत्यापित न होने के कारण Finder+ खोला नहीं जा सकता"* या *"Finder+ क्षतिग्रस्त है और खोला नहीं जा सकता"*।

फिर भी खोलने के लिए, इनमें से कोई एक तरीका चुनें:

- ऐप आइकन पर **राइट-क्लिक** (या Control-क्लिक) करें → **खोलें** → डायलॉग में फिर से **खोलें** पर क्लिक करें।
- या टर्मिनल में यह चलाएँ, फिर सामान्य रूप से लॉन्च करें:

  ```bash
  xattr -dr com.apple.quarantine /Applications/Finder+.app
  ```

- macOS 15 (Sequoia) और उसके बाद के संस्करणों पर, अगर राइट-क्लिक का रास्ता न दिखे, तो **सिस्टम सेटिंग्स → प्राइवेसी और सिक्योरिटी** पर जाएँ और **फिर भी खोलें** पर क्लिक करें।

**आवश्यकताएँ:** Apple Silicon (arm64) पर macOS। Intel बिल्ड अभी प्रकाशित नहीं हैं।

## आपका डेटा कहाँ रहता है

- **कैनवास फ़ाइलें** (आप कैनवास पर जो भी ड्रॉप करते हैं) `~/Documents/CanvasDesk/我的画布` में कॉपी कर दी जाती हैं। ऐप अपनी एक प्रति रखता है ताकि यह कभी मूल पथ पर निर्भर न रहे।
- **ग्राफ़, नोड की स्थिति और किनारे** ऐप की user data डायरेक्टरी के अंदर एक लोकल SQLite डेटाबेस में संग्रहीत होते हैं।
- **API कीज़** आपकी मशीन के लोकल स्टोरेज में रहती हैं। ऐप स्वयं कुछ भी कहीं अपलोड नहीं करता।

## सुरक्षा नोट्स

दो नोड जानबूझकर आपकी ओर से चीज़ें निष्पादित करते हैं, इसलिए अपने कैनवास के साथ वैसा ही व्यवहार करें जैसा आप एक स्क्रिप्ट के साथ करते हैं:

- **कमांड** — आपके लिखे कमांड को आपके सिस्टम शेल के माध्यम से, आपके यूज़र विशेषाधिकारों के साथ चलाता है।
- **कोड** — आपके लिखे JavaScript फ़ंक्शन बॉडी का मूल्यांकन करता है।

केवल वे ही कैनवास चलाएँ जो आपने स्वयं लिखे हैं या पूरे पढ़े हैं।

## सोर्स से बिल्ड करें

Node.js 20+ और macOS आवश्यक है।

```bash
npm install
npm run dev        # start in development mode
npm run typecheck  # tsc + vue-tsc
npm run build:mac  # produce a .dmg in dist/
```
