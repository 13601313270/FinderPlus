# Finder+

Холст визуальной автоматизации на основе узлов для macOS. Перетащите узлы на бесконечный холст, соедините их порты — и данные потекут по графу, превращая текст, изображения, вызовы LLM, HTTP-запросы и shell-команды в наглядный многоразовый конвейер.

## Что это такое

Finder+ — это десктопное приложение для построения **визуальных рабочих процессов**. Вместо написания скрипта вы размещаете узлы на холсте и соединяете выходной порт с входным. Значения передаются по связям, и каждый узел подсвечивается своим результатом, как только на его входы поступают данные.

Типичные сценарии использования:

- Пакетная обработка изображений: обрезка → сжатие → настройка качества → удаление фона
- Построение конвейеров промптов: текстовый шаблон → LLM → отображение JSON
- Генерация изображения по текстовому промпту с сохранением результата в папку
- Объединение HTTP API и локальных shell-команд без написания программы

## Загрузка

Последний релиз: **<https://github.com/13601313270/FinderPlus/releases>**

Откройте `.dmg`, перетащите **Finder+** в папку **Applications**, затем извлеките образ диска.

### Первый запуск в macOS

> **Эта сборка ещё не подписана и не нотаризована.** При первом запуске macOS заблокирует её с сообщением вроде *«Finder+ не удаётся открыть, так как разработчик не может быть проверен»* или *«Finder+ повреждён и не может быть открыт»*.

Чтобы всё-таки открыть приложение, выберите один из способов:

- **Щёлкните правой кнопкой** (или Control + щелчок) по значку приложения → **Открыть** → затем в диалоге нажмите **Открыть** ещё раз.
- Или выполните следующее в Терминале, а затем запустите приложение как обычно:

  ```bash
  xattr -dr com.apple.quarantine /Applications/Finder+.app
  ```

- В macOS 15 (Sequoia) и новее, если способ с правой кнопкой недоступен, перейдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.

**Требования:** macOS на Apple Silicon (arm64). Сборки для Intel пока не публикуются.

## Узлы

| Узел | Тип | Что делает |
| --- | --- | --- |
| Text Input | `text-input` | Выдаёт строку |
| Number Input | `number-input` | Выдаёт число |
| Boolean Input | `bool-input` | Выдаёт логическое значение |
| Text File | `txt-file` | Создаётся перетаскиванием файла `.txt` на холст |
| Image File | `img-file` | Создаётся перетаскиванием файла изображения на холст |
| Any File | `any-file` | Создаётся перетаскиванием файла любого другого типа |
| File Info | `file-info` | Считывает метаданные файла |
| Folder | `folder` | Контейнер, который собирает входящие файлы как дочерние узлы |
| Image Folder | `img-folder` | Контейнер для пакета изображений |
| Text Display | `text-display` | Показывает поступающий текст |
| JSON Display | `json-display` | Форматирует и отображает JSON |
| Image Preview | `image-preview` | Показывает изображение и может сохранить его на диск |
| String Concat | `string-concat` | Объединяет значения с помощью плейсхолдеров `$1 … $N` |
| Switch | `switch` | Условное ветвление |
| Human Review | `human-review` | Ставит значения в очередь на ручную проверку; выдаёт результат при **одобрении** или **отклонении** |
| LLM | `llm` | Чат-комплишен через настраиваемого провайдера |
| Image Generation | `image-gen` | Генерация изображения из текста через настраиваемого провайдера |
| Image Crop | `image-crop` | Обрезает изображение |
| Image Compress | `image-compress` | Сжимает изображение (WebAssembly) |
| Image Quality | `image-quality` | Настраивает качество кодирования |
| Image Overlay | `image-overlay` | Накладывает одно изображение на другое |
| Background Remove | `background-remove` | Удаляет фон (ONNX, локально на устройстве) |
| Code | `code` | Выполняет тело функции JavaScript |
| Command | `command` | Выполняет shell-команду |
| HTTP Request | `http-request` | Отправляет запрос HTTP/HTTPS |

## Где хранятся ваши данные

- **Файлы холста** (всё, что вы перетаскиваете на холст) копируются в `~/Documents/CanvasDesk/我的画布`. Приложение хранит собственную копию и никогда не зависит от исходного пути.
- **Графы, позиции узлов и связи** хранятся в локальной базе данных SQLite внутри каталога пользовательских данных приложения.
- **API-ключи** находятся в локальном хранилище на вашей машине. Само приложение ничего никуда не загружает.

## Замечания по безопасности

Два узла намеренно выполняют действия от вашего имени, поэтому относитесь к своему холсту так же, как к скрипту:

- **Command** — выполняет написанную вами команду через системную оболочку с вашими пользовательскими правами.
- **Code** — выполняет написанное вами тело функции JavaScript.

Запускайте только те холсты, которые вы написали сами или прочитали целиком.

## Сборка из исходного кода

Требуется Node.js 20+ и macOS.

```bash
npm install
npm run dev        # start in development mode
npm run typecheck  # tsc + vue-tsc
npm run build:mac  # produce a .dmg in dist/
```

## Технологический стек

Electron 44 · Vue 3 · TypeScript · Vite (electron-vite) · Less · vue-i18n · sql.js (SQLite через WebAssembly) · onnxruntime-web · img-compressor-wasm

Графовый движок (`src/main/engine/`) — это чистая логика без каких-либо зависимостей от Electron, напрямую используемая и главным процессом, и рендерером.
